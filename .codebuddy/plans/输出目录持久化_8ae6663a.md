## 用户需求

修复 CompressView 输出目录设置未持久化的问题：当前每次打开应用或添加新文件后，输出目录都需要重新选择，用户体验差。

## 核心功能

- 用户选择输出目录后自动保存到 localStorage
- 下次打开应用时自动恢复上次使用的输出目录
- 添加新文件时自动使用已保存的目录作为输出路径

## 技术方案

### 实现策略

沿用 settings.ts 中已有的 `theme` / `compressPreset` / `playerData` 三项持久化模式：`const KEY + loadXxx() + watch(xxx, persist)`，为 `outputDirectory` 补齐相同机制。

在 `useFileList.ts` 中导入 `useSettingsStore`，`setOutputDir` 完成后同步目录到 store，`addFiles` 创建 FileEntry 时若 store 有值则自动填充 outputPath。

### 实现细节

**settings.ts 修改（3 处）**

1. 新增 key：`const OUTPUT_DIR_KEY = 'snve-output-dir'`
2. 新增加载函数 `loadOutputDir()`：从 localStorage 读取，无则返回 `''`
3. 初始化时调用：`const outputDirectory = ref<string>(loadOutputDir())`
4. 新增 watch 持久化：`watch(outputDirectory, (val) => { try { localStorage.setItem(OUTPUT_DIR_KEY, val) } catch { /* ignore */ } })`

**useFileList.ts 修改（2 处）**

1. 顶部新增 `import { useSettingsStore } from '@/stores/settings'`，函数体内 `const settingsStore = useSettingsStore()`
2. `setOutputDir` 末尾新增 `settingsStore.setOutputDirectory(dir)` 同步到 store
3. `addFiles` 中创建 entry 时：读取 `settingsStore.outputDirectory`，若非空则按相同命名规则（取文件名去掉扩展名 + suffix）拼接 outputPath，即复用 `setOutputDir` 中的路径拼接逻辑

**CompressView.vue 无需修改**，它已通过 `useFileList().setOutputDir()` 操作。

### 性能与兼容性

- localStorage 读写同步，字符串存取无需序列化，O(1) 开销
- 向后兼容：首次使用或清除缓存后 `loadOutputDir()` 返回 `''`，行为与当前一致
- 不影响其他功能模块
